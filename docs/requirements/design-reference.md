## 2. Design a genuinely distinctive product

The finished interface must look professionally art-directed,
thoughtfully designed, and refined by a skilled human product team.

Do not settle for a generic AI-generated SaaS dashboard, a standard
admin template, or a predictable collection of cards.

Develop a coherent design system covering typography, color, spacing,
grids, component behavior, icons, interaction states, and motion.

Use deliberate composition, strong visual hierarchy, carefully
controlled contrast, purposeful whitespace, and meaningful visual
details. Every element should have a clear reason to exist.

Avoid generic AI design clichés, including excessive gradients,
gratuitous glassmorphism, repetitive rounded cards, floating
decorations, unnecessary animations, emoji-based iconography, and
oversized marketing typography on operational screens.

Do not choose a visual style simply because it is trendy. Research the
available approaches and select the one that best fits a live creative
competition.

## 3. Treat each experience as a distinct design problem

Create a consistent overall identity while giving each area its own
appropriate visual hierarchy:

-   **Admin control room:** Information-dense, precise, operational, and
    easy to control under time pressure.
-   **Participant workspace:** Focused, distraction-free, clear, and
    confidence-inspiring, especially during timed rounds.
-   **Round 1 quiz:** Excellent readability, obvious answer states,
    visible progress, and a highly legible countdown.
-   **Round 2 image recreation:** A creative workspace with clear task
    status, prompt/evidence handling, attempt information where
    verifiable, and submission confirmation.
-   **Round 3 logo design:** A clean case-study presentation, submission
    workspace, and polished preview of the final logo.
-   **Judging dashboard:** A highly efficient visual-review experience
    with comparison layouts, submission galleries, clear scoring, and
    minimal friction.
-   **Leaderboard:** Carefully structured rankings, readable scores, and
    meaningful status indicators.

Do not force every screen into the same card-based layout. Use the
layout that best supports each workflow.

## 4. Use design skills throughout implementation

The selected skills must influence the actual work, not merely appear in
a checklist.

Use them to:

-   Establish the design direction before coding.
-   Evaluate typography, layout, density, color, and component choices.
-   Improve interaction patterns and microcopy.
-   Refine transitions, loading states, error handling, and empty
    states.
-   Identify generic-looking design decisions and replace them with
    intentional alternatives.
-   Improve accessibility and keyboard interaction.
-   Review the rendered implementation and iterate on visible
    weaknesses.

Inspect the real application in a browser whenever the environment
supports it. Evaluate the actual rendered screens rather than trusting
the source code alone.

## 5. Establish quality gates

Before considering the design complete:

1.  Review the key screens using the selected design and critique
    skills.
2.  Check visual consistency across all three rounds and the admin,
    participant, and judging experiences.
3.  Verify typography, alignment, spacing, contrast, responsiveness, and
    readability.
4.  Test the actual timer, dialogs, forms, navigation, submission
    feedback, and interactive states.
5.  Review accessibility and keyboard navigation.
6.  Remove placeholder controls, fake metrics, generic layouts, and
    unfinished states.
7.  Refine the interface until it feels deliberate, cohesive, and
    professionally finished.

Do not invent a visual direction without examining the available skills.
**Research the options, select the strongest combination, justify the
choice briefly, and use it to produce the best possible design for this
specific product.**

The goal is not merely to make the application look attractive. The goal
is to make it feel like a carefully crafted, production-quality
competition platform that does not look obviously AI-generated.
